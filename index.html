Параметры проекта

Производство работает по внутреннему плану: срок и отклонения в панели считаются от даты начала работ и внутреннего срока. Дата аванса и договорной срок используются только для выгрузки клиентского сайта и в панели не отображаются.

Этапы план-графика

Даты правятся здесь, прогресс - на вкладке "План-график".

Шаблон задачи для сотрудников текст, который добавляется к каждому плану в ТГ

Порядок в сообщении: заголовок с датой - шапка - задачи с объемами - состав бригады - комментарий к плану - этот блок напоминаний.

Командная синхронизация общие данные для всех сотрудников

Настройки подключения хранятся на каждом устройстве отдельно, рабочие данные - общие. Панель забирает изменения при открытии страницы, при возврате на вкладку и по кнопке обновления в шапке. Порядок настройки - в файле ИНСТРУКЦИЯ.md.

Данные

Кнопка "Выгрузить данные для клиентского сайта" скачивает файл client-data.js - замените им одноименный файл в репозитории GitHub, и клиентский сайт покажет актуальный прогресс. Данные хранятся в браузере на этом устройстве. Для переноса или совместной работы - выгружайте JSON и импортируйте на другом устройстве. Делайте экспорт после каждого дня заполнения.
